# Basic Chatbot & SQLite Database Ticket Classifier

## 📌 Project Overview

This project consists of two basic applications:

1. **Basic Chatbot:** A simple chatbot application designed to interact with users and respond to their queries.

2. **SQLite Database Ticket Classifier:** A ticket classification system that uses an SQLite database to store, manage, and organize support tickets efficiently.

The project demonstrates chatbot functionality, database management, and ticket classification.

## 🚀 Features

### 1. Basic Chatbot

- Interactive conversation with users.
- Accepts user messages and provides responses.
- Simple and user-friendly interface.
- Handles basic user queries.

### 2. SQLite Database Ticket Classifier

- Uses SQLite for database management.
- Stores and manages support ticket information.
- Classifies tickets based on their content or category.
- Helps organize and retrieve ticket records.
- Maintains structured ticket data.

## 🛠️ Technologies Used

- **Python** – Application development.
- **SQLite** – Database management and storage.
- **SQL** – Database queries and operations.

## ⚙️ Installation and Setup

1. Clone the repository:

   ```bash
   git clone <repository-url>
   ```

2. Navigate to the project directory:

   ```bash
   cd basic-chatbot
   ```

3. Install the required dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Run the respective Python application files.
